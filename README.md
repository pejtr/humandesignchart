# Humanoid Design Chart

A web-based interactive application for exploring and visualizing Human Design charts.

## Features

- Interactive Human Design chart visualization
- Real-time chart generation based on user input
- Integration with Human Design system data

## Technologies

- Frontend: React 19 + Tailwind CSS
- Backend: Node.js with Express and tRPC
- Database: Drizzle ORM with PostgreSQL
